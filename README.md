# Spring JWT Guard

API REST desenvolvida com **Java e Spring Boot** para gerenciamento de usuários e autenticação utilizando **Spring Security e JSON Web Tokens (JWT)**.

O projeto tem como objetivo implementar um fluxo de autenticação stateless, controle de acesso baseado em papéis (*Role-Based Access Control — RBAC*) e boas práticas no desenvolvimento de APIs REST.

## Tecnologias utilizadas

- **Java** — linguagem de programação.
- **Spring Boot** — framework para desenvolvimento da aplicação.
- **Spring Security** — autenticação e autorização.
- **JWT (JSON Web Token)** — autenticação baseada em tokens.
- **BCrypt** — criptografia de senhas.
- **Spring Data JPA** — persistência e acesso aos dados.
- **Hibernate** — ORM para mapeamento objeto-relacional.
- **PostgreSQL** — banco de dados relacional.
- **Flyway** — versionamento e gerenciamento de migrações do banco de dados.
- **Bean Validation** — validação de dados de entrada.
- **Docker e Docker Compose** — containerização e gerenciamento do ambiente de desenvolvimento.
- **Maven** — gerenciamento de dependências e build do projeto.
